# Stochastische Calculus - Benutzerdefiniertes Lehrbuch

Dieses Buch enthält Dark Souls-stil Herausforderungen (Boss Challenges) vor jedem Kapitel.

## Kompilierung

Um das Buch zu kompilieren, verwenden Sie:

```bash
pdflatex main.tex
pdflatex main.tex  # Zweimal für korrekte Referenzen
```

Oder mit `latexmk`:

```bash
latexmk -pdf main.tex
```

## Struktur

- `main.tex` - Hauptdatei des Buches
- `chapters/chapter01.tex` - Kapitel 1: Martingales in diskreter Zeit

## Features

- ⚔️ **Boss Challenges** - Schwere mathematische Probleme im Dark Souls Stil
- Vollständige LaTeX-Struktur für ein Lehrbuch
- Deutsche und englische Notation
- Theoreme, Definitionen, Beispiele und Übungen
